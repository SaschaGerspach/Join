# Join – Kanban Task Manager

A frontend web application for managing tasks in a Kanban-style board.
Users can create, edit and organize tasks via drag & drop and assign them to contacts.

## Live Demo

Open in browser: [Join](https://join.sascha-gerspach.de/)

## Features

- Create, edit and delete tasks
- Drag & drop between status columns (To Do, In Progress, Await Feedback, Done)
- Assign contacts and categories to tasks
- Form validation and user feedback
- Tasks and contacts are stored remotely using Firebase Realtime Database
- Guest login for quick testing

## Technologies

- HTML
- CSS
- JavaScript
- Firebase Realtime Database

## How to run locally

- Download or clone the repository
- Open `index.html` directly in your browser  
  (No build step or installation required)

## Notes

This project focuses on frontend state management, user interaction and communication with a remote database.
